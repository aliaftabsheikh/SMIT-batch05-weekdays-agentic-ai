How it works

From install to first review in five minutes.

No model training. No data pipeline to configure. Connect your repo and go.

  1. Install the GitHub App

    Authorize ReviewPilot on the repos you choose. Read-only access to code, write access only to PR comments. Nothing reaches outside your request.

  2. Open a pull request

    ReviewPilot analyzes the diff the moment a PR is opened or updated. No CLI commands, no CI step to wire up, no YAML file to write.

  3. Act on targeted feedback

    Inline comments appear on the exact lines that matter — labelled by issue class and severity, each with a suggested fix. Merge with confidence.

Customization

Your rules. Your standards. Zero config drift.

Every team has hard lines and deliberate trade-offs they've learned to live with. ReviewPilot lets you encode both — without writing a YAML spec the size of a novel.

  • Per-repo rule sets — different standards for your public API versus your internal admin tooling.
  • Feedback on feedback — mark a comment "not relevant" once, and that pattern won't resurface on your repo.
  • Merge blocking — block PRs on critical issues, surface warnings without blocking, or silence style notes entirely.
  • Works beside your linter — ReviewPilot adds a judgment layer on top of ESLint, Ruff, or Rubocop, not a replacement for them.
FAQ

The questions we hear before people sign up.

Does ReviewPilot train on my private code?

No. Your code is analyzed in an isolated environment and never retained or used to update any model. Only the diff and your repo's rule config are sent to the model — nothing from the rest of your codebase. Read the full details in our privacy policy.

How does it compare to GitHub Copilot for PRs or CodeRabbit?

ReviewPilot is built around reducing false positives. We track which comments your team dismisses and suppress that pattern going forward. Teams on a mature repo report 90%+ of our comments are actionable, versus 40–60% for generic tools. We also support merge-blocking on critical issues natively, which most alternatives require external CI logic to replicate.

Which languages and frameworks do you support?

Python, JavaScript/TypeScript, Go, Ruby, Java, Rust, and C# have first-class support with language-specific security rules and framework awareness (Django, Express, Rails, Spring, etc.). PHP, Kotlin, and Swift are in beta. All other languages receive structural and logic analysis without framework-specific rules.

We already run a thorough human review process. Why add this?

Human reviewers excel at judgment calls — architecture, naming, readability. They're inconsistent at mechanical checks when tired or under time pressure. ReviewPilot owns the mechanical layer so your reviewers can focus where their judgment actually moves the codebase forward. The typical result is faster reviews, not fewer people doing them.

Does it work with GitLab or Bitbucket?

GitLab Cloud and GitLab self-managed are available now in public beta. Bitbucket Cloud is on the roadmap for Q3 2026. GitHub Cloud and GitHub Enterprise Server 3.10+ are fully supported today.

What happens when the 14-day trial ends?

You'll be prompted to choose a plan. If you do nothing, the account moves to the free tier: unlimited reviews on public repos, up to 3 private repos, 100 PR reviews per month. No card is charged and no service is interrupted. Paid plans for teams start at $18 per seat per month.
